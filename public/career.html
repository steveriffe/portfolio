Flagship Enterprise Case Study

Automating a 90-Workbook Tableau-to-Sigma Migration

At Pacific Life, legacy business intelligence modernization required migrating 90 complex production workbooks from Tableau to Sigma Computing. Rather than manually rebuilding calculated fields and layouts by hand over 12 months, Steve engineered an automated agentic translation harness in VS Code.

PHASE 1 · DECOMPILATION

XML & Formula Parsing

Unpacked proprietary Tableau .twbx XML structures to catalog data sources, joins, LOD (Level of Detail) expressions, and parameter actions into machine-readable JSON ASTs.

PHASE 2 · AGENTIC TRANSLATION

Semantic AST Mapping

VS Code AI agents translated complex Tableau calculation syntax into Sigma formula language and Snowflake SQL pushdown semantics with zero manual keystrokes.

PHASE 3 · VERIFICATION

Automated Parity Testing

Built an automated regression test harness comparing mathematical query outputs between Snowflake, Tableau Server, and Sigma workbooks to prove 100% parity.

Outcome: Cut migration timeline from an estimated 10 months down to under 8 weeks while establishing automated visual and mathematical parity tests.
